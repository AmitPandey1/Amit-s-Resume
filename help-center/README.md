# Help Center

## How do I download the resume?

Select **Download Resume** on the portfolio. The link serves `/Amit-Pandey-Resume.pdf`. If it is unavailable, maintainers should confirm that `web/public/Amit-Pandey-Resume.pdf` exists and is included in the deployed build.

## Why did Send Message open my email application?

The form prepares a draft using `mailto:`. Review and send the message in your email application. The website does not deliver it automatically. If nothing opens, configure a default mail application or use the displayed email address directly.

## How do I save the contact?

Select **Save to Contact** or use the contact card. Your device opens the vCard at `/amit-pandey.vcf`; follow its import prompts. QR scanning depends on the URL encoded in the static QR asset, so maintainers should verify it after domain changes.

## How do I view all projects and details?

Use **View All Projects** to show the remaining work projects. Select a project title to expand its contributions and links. On mobile, open the Projects section first if it is collapsed.

## Why did my code edit not change the homepage?

The current page is `web/src/pages/HomePage.jsx`. Components such as `Hero.jsx`, `Header.jsx` and `ResumeSection.jsx` are not mounted by the current application tree. Follow the imports from `web/src/App.jsx` before editing a component.

## Why is the downloaded resume out of date?

The PDF is static and is not regenerated by Vite. From the repository root run:

```sh
npm run resume:generate --workspace web
npm run build
```

The generator requires Chrome or Chromium. Set `CHROME_PATH` to the executable if it cannot be found. Inspect the generated PDF and include it with the source changes before deployment.

## Why does a new project card fail to render?

Every project needs `tags` and `details` arrays. A project without an `image` needs a matching `artwork` entry keyed by its `index` in `web/src/components/ProjectCard.jsx`. There is no fallback illustration for unknown indexes.

## Why does linting fail?

The workspace lint script references `eslint.config.mjs` and `eslint.unicode-escapes-formatter.mjs`, which are absent in this checkout. Restore the intended configuration or update the script before relying on lint results. A build alone does not validate all lint rules or browser behavior.

## Where are API keys, accounts and billing configured?

They are not features of this application. Hosting and GitBook accounts are managed separately by their respective services. The portfolio requires no application API keys.

## What should I include when reporting a problem?

Include the affected page or feature, reproduction steps, expected and actual behavior, browser, screen size and relevant error text. For development problems, also include the command and Node version. Use the project's existing contact or repository workflow; these docs do not establish a separate support service.
