# Documentation

Learn how the portfolio works and how to maintain it. Start with local development, then follow the rendering flow from `web/src/main.jsx` through `App.jsx` to `pages/HomePage.jsx`.

- [Local development](getting-started.md) — requirements, npm commands and checks.
- [Architecture and code map](architecture.md) — active components, state, styling and data flow.
- [Updating content](content.md) — profile, project cards, assets and contact information.
- [Resume PDF](resume-pdf.md) — regenerate the downloadable resume using Chrome or Chromium.
- [Deployment and GitBook](deployment.md) — portfolio hosting and documentation organization.

File paths shown in code formatting are relative to the repository root. The active homepage uses shared data plus some inline content; older standalone components are not mounted by the current page.
